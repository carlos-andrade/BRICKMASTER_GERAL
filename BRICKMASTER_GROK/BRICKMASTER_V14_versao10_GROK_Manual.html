3. Fluxo / Agressão

ModoComo funciona
UsarAgressaoNativa = false (padrão) Proxy universal: posição do fechamento no range (0–100) + volume anômalo / força do volume + lado do VWAP
UsarAgressaoNativa = true Usa AgressionVolBalance (requer Profit Pro/Ultra ou módulo Scalper)
  • FluxoComprador / FluxoVendedor / FluxoNeutro
  • Plot19 — ProxyAgressao (0–100)

4. Integração com o sistema

  • Reforço leve no Score quando fluxo alinha com o Contexto
  • Se ExigirFluxo = true, a execução só libera a favor do fluxo
  • Alertas/PlotText: [C] FLUXO COMPRADOR, [V] FLUXO VENDEDOR, preço vs VWAP
