1. O que esta versão contém

Módulos inclusos:

2. Módulo Base (herdado)

  • Linha branca da Abertura do Dia
  • 8 bandas percentuais (±0,50% / ±1% / ±2% / ±3%)
  • Médias Curta (M9) e Longa (M25) que reiniciam a cada dia a partir da abertura

3. Módulo 01 — Ciclo de Eventos

Para cada uma das 8 bandas o sistema detecta a seguinte sequência:

EventoCondição
Toque High alcança a banda de cima ou Low alcança a banda de baixo
Aceitação Close fecha além da banda (rompe e aceita o lado)
Rejeição Tocou a banda, mas o Close voltou para dentro + pavio mínimo
Armadilha Rejeição forte (pavio ainda maior que o mínimo de rejeição)
Confirmação Versão simples: Armadilha/Rejeição + candle na direção oposta ao toque
Observação: A confirmação desta versão é simples (ainda sem filtros de VWAP, M9 ou volume). Filtros avançados serão adicionados em módulos posteriores.

3.1 Variáveis geradas (exemplos para ±1%)

  • TocouMais1 / TocouMenos1
  • AceitouMais1 / AceitouMenos1
  • RejeitouMais1 / RejeitouMenos1
  • ArmadilhaMais1 / ArmadilhaMenos1
  • ConfirmouArmadilhaMais1 / ConfirmouArmadilhaMenos1
  • ConfirmouRejeicaoMais1 / ConfirmouRejeicaoMenos1

O mesmo padrão existe para ±0,50%, ±2% e ±3%.

3.2 Inputs de calibração do ciclo

InputPadrãoFunção
MinPavioRejeicao 0.40 Pavio mínimo (em % do range do candle) para registrar Rejeição
MinPavioArmadilha 0.55 Pavio mínimo (em % do range) para registrar Armadilha (mais rigoroso)
