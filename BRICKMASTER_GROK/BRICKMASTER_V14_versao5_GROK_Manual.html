1. O que esta versão adiciona

Módulo 05 — Recusa
Detecta rejeição estrutural do candle (corpo/pavio/eficiência) com machine de estados e gate de banda.

2. Regras do Módulo de Recusa

  • Rejection Index (RI) = maior pavio / range do candle
  • Gate obrigatório: o candle precisa tocar alguma banda (Meio / ±1 / ±2 / ±3 / Abertura)
  • RecusaAlta: RI alto + pavio superior dominante + candle de baixa + gate
  • RecusaBaixa: RI alto + pavio inferior dominante + candle de alta + gate
  • Machine de estados 0–7: acumula evidências; estado 7 = candidato a reversão
  • Peso no Score: +3 (PesoRecusa)
  • Somente leitura: não gera ordem

3. Estados da Recusa

EstadoSignificado
0Neutro — sem evidências
1–3Acumulando evidências iniciais
4–6Progressão / Recusa ativa
7Candidato a reversão (confirmação)

5. PaintBar

  • Recusa confirmada de baixa → verde-água (força compradora)
  • Recusa confirmada de alta → rosa/vermelho (força vendedora)
