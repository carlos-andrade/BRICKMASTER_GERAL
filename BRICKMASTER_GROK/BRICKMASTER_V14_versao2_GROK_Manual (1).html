1. Regra Obrigatória do Sistema (Arquitetura)

REGRA OBRIGATÓRIA — NÃO PODE SER IGNORADA

1. É obrigatório inserir uma regra de coloração nos candles (PaintBar com hierarquia de prioridade).
2. É obrigatório usar o sistema com fonte (PlotText / Alert com fonte legível e offset controlado).

Todo evento relevante detectado pelo sistema deve ser:
  • Validado
  • Pesado no Score (quando o módulo existir)
  • Sinalizado no candle de origem (PaintBar)
  • Plotado com texto legível (sistema de fonte)
Princípio fundamental do Brickmaster:
“Todo evento relevante deve ser validado, pesado no Score, sinalizado no candle de origem e plotado.”

2. O que esta versão adiciona

Módulo 02 — PaintBar (Cores)
Os eventos detectados no Módulo 01 agora aparecem visualmente no gráfico através da pintura dos candles, seguindo a regra obrigatória de coloração.

3. Hierarquia de Prioridade (do mais importante para o menos)

Só um evento pinta cada candle. O de maior prioridade ganha. Esta hierarquia é a regra de coloração oficial desta versão.

PrioridadeEventoCorSignificado
P1 Confirmação Armadilha ±1% Vermelho puro / Verde puro Sinal operacional mais forte
P2 Confirmação Armadilha ±0,5% / ±2% / ±3% Coral, Violeta, Magenta, Índigo, Carmim, Cobalto Confirmações de outras bandas
P3 Confirmação Rejeição ±1% Marrom-alaranjado / Azul-petróleo Rejeição confirmada na banda principal
P4 Armadilha não confirmada ±1% Âmbar / Azul royal Alerta forte, ainda sem confirmação
P5 Rejeição não confirmada ±1% Pêssego / Azul-céu Rejeição mais fraca
P6 Aceitação ±1% Verde-azulado / Roxo Preço aceitou o lado da banda
P7 Outros eventos (±0,5% / ±2% / ±3%) Amarelo-dourado, Azul-celeste, Bege, Azul claro Eventos secundários

4. Controle de sobreposição

Variável de controle: PintouEvento
Assim que um evento de prioridade mais alta pinta o candle, a flag vira true e nenhum evento de prioridade inferior consegue pintar o mesmo candle.
Isso garante que a regra de coloração seja respeitada.

5. Sistema com Fonte (obrigatório nas próximas versões)

A partir do Módulo de Alertas (e já como regra permanente):

• Todo evento importante deve ser acompanhado de PlotText com fonte legível
• Usar offsets rotativos para evitar sobreposição de textos
• Prefixo padronizado: [C] / [V] / [$] / [!]
• Incluir o número do candle no texto
• Fonte e tamanho devem garantir legibilidade no gráfico
