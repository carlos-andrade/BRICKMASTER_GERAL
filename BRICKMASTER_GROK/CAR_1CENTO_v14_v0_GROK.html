1. Objetivo desta versão

Esta é a versão zero do Brickmaster V14. Ela contém somente a fundação do sistema:

  • Cálculo da Abertura do Dia
  • Cálculo das 8 bandas percentuais (±0,50% / ±1% / ±2% / ±3%)
  • Cálculo das duas médias de variação das bandas (Curta e Longa)
  • Plotagem limpa das linhas e das médias
Nada mais foi incluído.
Não há Score, não há execução de ordens, não há alertas, não há volume anômalo, não há módulo de abertura zero, não há módulo de recusa. Esta versão serve exclusivamente como base sólida e limpa para construir os próximos módulos.

2. O que o código faz (passo a passo)

2.1 Detecção de Novo Dia

A cada candle o sistema verifica se a data mudou:

NovoDia := (Date <> Date[1]);

Se for verdadeiro, captura a abertura oficial do pregão:
AberturaDia := Open;

2.2 Cálculo das Bandas

Todas as bandas são calculadas a partir da abertura do dia (não do candle atual):

BandaFórmulaCor no gráfico
±0,50% AberturaDia * (1 ± PercentualMeio/100) Amarelo suave
±1,00% AberturaDia * (1 ± PercentualAlvo1/100) Azul
±2,00% AberturaDia * (1 ± PercentualAlvo2/100) Verde
±3,00% AberturaDia * (1 ± PercentualAlvo3/100) Vermelho

2.3 Variação Percentual Atual

É a distância percentual do fechamento atual em relação à abertura do dia:

VariacaoAtual := ((Close - AberturaDia) / AberturaDia) * 100;

Essa variável é a matéria-prima das duas médias.

2.4 Médias de Variação das Bandas

Em vez de fazer média simples de preço, o sistema faz média da variação percentual e depois transforma de volta em preço:

  • Média Curta (padrão 9 períodos) → linha laranja
  • Média Longa (padrão 25 períodos) → linha roxa

Isso permite que as médias “viajem” junto com as bandas e mostrem a tendência da variação do dia.

5. Como usar

  1. Copie o arquivo BRICKMASTER_V14_versao0_GROK.src para a pasta de estratégias do Profit.
  2. Abra o Editor de Estratégias e carregue o arquivo.
  3. Importante: carregue como Estratégia (não como Indicador).
  4. Aplique no gráfico de 1 minuto ou 5 minutos do WIN ou do ativo desejado.
  5. As linhas das bandas e as duas médias aparecerão automaticamente a partir da abertura do dia.
Atenção: Esta versão ainda não opera. Ela apenas desenha a estrutura visual base. Nas próximas versões (V14_versao1, versao2...) serão adicionados os módulos de eventos, Score, execução, trailing etc.
