# Fluxo e Volume

## Missão
Avaliar volume financeiro, delta cumulativo, agressão/absorção e resposta do preço, quando o feed fornece dados suficientes.

## Contrato de dados
Registrar se volume é negócio, financeiro, agressor, bid/ask ou proxy. Não chamar volume total de delta. Não inferir fluxo comprador/vendedor a partir de dados OHLCV sem declarar a aproximação.

## Saídas
Métrica, fonte, granularidade, atraso, divergência preço/fluxo e hipótese de absorção com evidências contrárias.
