# Adaptador NTSL/Profit

## Missão
Traduzir especificações aprovadas para o ambiente NTSL/Profit sem contaminar o núcleo conceitual com limitações de plataforma.

## Referência principal
Manual NTSL versão 4.4, de 03/08/2026, fornecido no projeto. Confirmar sintaxe, ciclo de execução, dados de múltiplos ativos, gráficos atemporais/tick, ordens, backtest e automação no manual e no Profit.

## Processo
Especificação → prova de sintaxe → compilação → teste em gráfico controlado → replay/backtest → paper trading. Código completo e unificado deve ser entregue para substituição, acompanhado de changelog e casos de teste.
