## Contexto Histórico

Este arquivo estabelece regras de documentação de testes do Módulo 001.

Esta pasta guarda apenas evidências produzidas por testes reais do módulo isolado.

Cada evidência deve indicar:
- ID do teste.
- Data e hora.
- Instrumento e contrato/símbolo.
- Tipo de gráfico e configuração relevante.
- Versão do Profit/NTSL, quando disponível.
- Resultado esperado e observado.
- Estado PASS, FAIL ou BLOCKED.
- Referência ao defeito ou à correção, quando aplicável.

Não guardar capturas ilustrativas como se fossem resultados de execução. Não declarar aprovação sem evidências verificáveis.
